# sakkal-majalla-font

## Usage

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/mahmoudsaeedua74/sakkal-majalla-font@main/font.css">
```

or in CSS:

```css
@import url("https://cdn.jsdelivr.net/gh/mahmoudsaeedua74/sakkal-majalla-font@main/font.css");

body {
  font-family: "Sakkal Majalla", sans-serif;
}
```
